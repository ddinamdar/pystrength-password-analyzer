# PyStrength — Password Strength Analyzer

A command-line tool to evaluate password strength
and give improvement suggestions.

## Features
- Scores passwords on 6 security criteria
- Detects commonly used/leaked passwords
- Actionable improvement suggestions
- Zero external dependencies

## Usage
```bash
python password_checker.py
```
